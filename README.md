## About CanvasFlow

CanvasFlow gives you a visual canvas right inside the browser, built around everyday graphic design work. Shapes, text, and images can be placed and arranged freely on the workspace, and ready-made templates offer a head start whenever you would rather not begin from an empty page.

Everything runs on the client side as a progressive web app, with caching that keeps the app available offline. Finished designs leave the editor as PNG files, while project data stays on your own device. That combination makes CanvasFlow a good fit for lighter design tasks that should not depend on a server-side editing backend.

---

## Features

- Compose layouts by dragging shapes, text, and images onto the canvas
- Kick off new work from a set of built-in design templates
- Save finished canvases as PNG images
- Keep working when the connection drops thanks to offline caching
- Retain project information locally on the device
- Operate entirely through a client-side web application
- Evaluate the app with a 7-day free trial
- Unlock permanently with a one-time purchase, which includes the available watermark removal feature

### Run from a local clone

```bash
git clone https://github.com/marco-parker1967/canvasflow-design-template-hub.git
cd REPO
```

Any static web server can host the project directory. Point it at the folder, then open the resulting local address in your browser. One example:

```bash
python3 -m http.server 8080
```

Go to `http://localhost:8080/` to load the application.

## Usage

1. Launch CanvasFlow in a compatible web browser.
2. Pick a starter template or begin with an empty canvas.
3. Drag shapes, text, and images into the workspace.
4. Position and polish the composition inside the canvas editor.
5. Export the finished design as a PNG file.
6. Return to the app on the same device to reach your locally stored project data.

For offline use, load the hosted app once while online so the PWA can cache everything it needs.

## Configuration

The standard browser workflow needs no separate server configuration file. The browser handles caching of application resources, and project data lives in local device storage.

Most browsers let you inspect or clear this storage from their site settings. Be aware that wiping stored site data can also delete CanvasFlow projects saved on the device.

## Requirements

- A current web browser with PWA and local storage support

## FAQ

### Where do I find CanvasFlow?

Open the [latest hosted build](https://marco-parker1967.github.io/canvasflow-design-template-hub/) to start the web PWA.

### Does CanvasFlow work without a connection?

Offline caching is built in. Load the app once while connected, then rely on the cached copy whenever the browser and stored resources allow offline operation.

### Where is my work saved?

Projects are kept on the device through browser storage. CanvasFlow is not presented as a synchronized, server-backed workspace.

### How can I export a design?

Finish arranging the canvas, then trigger the PNG export control to save the design as an image file.

### Can I try it before buying?

Yes. CanvasFlow offers a 7-day free trial, and a one-time unlock is available as well. Watermark removal is among the features included with the unlock.

### The app will not load - what now?

Make sure JavaScript is enabled, reload the page, and verify that the browser has storage available. In offline mode, reconnect to the internet and open the hosted build again so cached resources can refresh.

### How do updates arrive?

Visit the hosted build while online. The PWA's usual cache refresh behavior then pulls in updated application resources.
